# Scott2

Scott2 is a collection of Jupyter notebooks exploring neuro-symbolic reasoning,
causal models, and prototype intelligence systems. The notebooks are independent
experiments rather than a packaged Python library.

## Notebooks

| Notebook | Description |
| --- | --- |
| [`connectome-transformer-demo.ipynb`](connectome-transformer-demo.ipynb) | A Python implementation and demonstrations of ConnectomeTransformerUltra, including knowledge-graph, symbolic, and causal reasoning. |
| [`connectome-transformer-model-development.ipynb`](connectome-transformer-model-development.ipynb) | Development experiments for ConnectomeTransformerUltra, including external data pathways, model optimization, and stress tests. |
| [`connectome-transformer-extended-experiments.ipynb`](connectome-transformer-extended-experiments.ipynb) | Extended reasoning and autonomous-system experiments, with sections on oncology and drug discovery. |
| [`superasi-core.ipynb`](superasi-core.ipynb) | A self-contained SuperASI Core prototype covering sparse distributed representations, persistent memory, verification, and tests. |

## Running a notebook

Open a notebook in Jupyter or use its Google Colab badge. Run cells in order
from a fresh kernel; dependencies and runtime assumptions can differ between
notebooks. Review cells before running them, especially where they access files
or external resources. These notebooks are exploratory prototypes, not validated
scientific or production systems.
